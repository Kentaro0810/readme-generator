# README作成ツール

プロジェクト情報からGitHub向けのREADME.mdを作成する、サーバー不要のブラウザーツールです。

## 主な機能
- READMEの主要章を選択して作成
- リアルタイムプレビュー
- Markdownソース表示
- クリップボードへのコピー
- README.mdとしてダウンロード
- 下書きのlocalStorage保存
- スマートフォン・タブレット・PC対応

## 公開方法
GitHubで `readme-generator` というPublicリポジトリを作成し、`index.html`、`style.css`、`script.js`、`README.md`をアップロードします。Settings → Pagesでmainブランチの `/ (root)` を公開します。

## 注意
秘密情報、APIキー、アクセストークン、実際のパスワードは入力しないでください。
